# 📚 Landing Page — Escritora

Projeto desenvolvido com foco em praticar desenvolvimento front-end, responsividade e construção de interfaces modernas para uma landing page autoral voltada para uma escritora.

O objetivo desta primeira versão foi criar uma experiência visual elegante, simples e acolhedora, destacando:

- apresentação da escritora;
- chamada principal;
- identidade visual;
- responsividade;
- estrutura semântica em HTML;
- estilização moderna com CSS.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (interações básicas)
- Git & GitHub

## 🎨 Objetivos da V1.0

Nesta primeira versão, o foco principal foi:

- estruturar a landing page;
- construir uma interface responsiva;
- aplicar boas práticas iniciais de organização;
- praticar posicionamento com Flexbox;
- melhorar a experiência visual do usuário;
- criar uma base sólida para futuras melhorias.

## 📱 Responsividade

A página foi desenvolvida pensando em diferentes tamanhos de tela:

- desktop;
- tablet;
- mobile.

### ✨ Funcionalidades atuais

- Layout moderno e minimalista;
- Sessão principal de apresentação;
- Botões de chamada para ação;
- Estrutura organizada para futuras expansões;
- Navegação simples e intuitiva.
